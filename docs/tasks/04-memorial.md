## 決めること
- 担当者を指定しないときの候補の出し方（担当者ごとに分けて並べる案）
  - 【決定】案から変えて、**日ごと → 開始時刻ごとに、その時間に空いている担当者を並べる**（MCP では「候補: [{ 日付, 祥月命日より前, 時刻: [{ 開始, 終了, 担当できる人 }] }]」と「担当者ごとの候補の件数」を返す）。担当者ごとに分けると、同じ日時が担当者の数だけ繰り返されて長くなり、「この日時に誰が空いているか」（場面 0 の「3/15 は住職だけが 10 時に空いている」）を比べにくいため。担当者で絞るときは `officiant`（名前か役職）を渡す
- 候補の件数の上限
  - 【決定】開始時刻で **200 件**（初期値。500 件まで指定できる）、一度に調べる期間は **62 日まで**。「3 月に」と言われて 1 か月まるごと（31 日 × 6 枠 = 186 件）を調べても、命日より前の日で切れて 3/15 などが落ちないようにするため。上限で切ったときは「期間を絞ってください」と返す

### そのほかに決めたこと
- 【決定】`verify_memorial` は故人の検索もする（`person_id` か、俗名・続柄・法号・世帯）。候補が複数なら「要確認」として、法号・没年・世帯（住所）・希望の年の回忌を並べて返し、1 人に決めない。続柄は部分一致で探すので「父」で「祖父」も当たるが、続柄がちょうど同じ人がいればその人たちに絞る（場面 0 で「山田」「父」→ 本町の太郎さんと北町の太一さんの 2 人になる）
- 【決定】希望の年は「希望日 → 希望の時期の始まり → 年 → 依頼の回忌の年 → 次の年忌」の順に決める。「3 月に」のように年がないときは、今日より後でいちばん近いその月を Claude が指定する（ツールの説明に書いた）
- 【決定】命日の当日は「命日より前」に含める。希望の時期の一部が命日より後のときは、警告ではなく「命日までの日を勧める」案内にする（全部が命日より後のときだけ警告）。複数霊位供養では、故人のうちいちばん早い祥月命日で「命日より前」を判定する
- 【決定】`book_memorial_service` は、回忌の食い違いや命日より後の日を**止めずにプレビューの注意に出す**（繰り上げて営むこともあるため。spec §12 E-1）。同じ故人の同じ回忌がすでに確定していれば conflict にする（二重の登録を防ぐ）
- 【決定】法要の担当者は `is_officiant` のスタッフだけにする（候補も確定も）。MCP では名前か役職（「住職」）で指定する（02 の `resolveStaff`）
- 【決定】施主を省略したときは、申し込みの施主（なければ申し込んだ本人）、申し込みがなければ世帯の窓口（なければ世帯主）にする。プレビューに出すので、違えば直せる
- 【決定】担当者の予定と本堂の予約は、押さえる時間（お寺: 法要の前後 10 分ずつ、自宅・墓前: 行きと帰りの移動時間）で作る。法要そのものの時間（`start_at` と `duration_min`）は `memorial_services` に持つ
- 【決定】確定の確かめ直しは、担当者の空きを自分で確かめ、本堂の空きは 03 の `createReservation`（排他制約まで含む）に任せる（プレビューでは本堂も先に確かめる）。担当者の予定には排他制約がないので、確定はお寺ごとの advisory lock で 1 件ずつ行う
- 【決定】法要を取り消すと、ひもづく申し込みは「受付済み」（requested）に戻し、法要とのひもづけを外す（日時を決め直せるように。不要ならお断りにする）。取り消しは管理画面からだけ（ドメイン層でも `channel = mcp` を拒む）
- 【決定】電話の申し込み（自動で作るもの）の `preferred_periods` は空にする（その場で日時が決まったため）
- 【決定】`createMemorialRequest` の希望の時期は、過ぎた日を含まず、3 年先まで。第 3 引数で `today` を渡せる（テストとシードのため）。ポータルの操作者（`personId` を持つ操作者）だけが呼べる
- 【決定】`getHouseholdMemorialSchedule` の `upcoming` は、祥月命日が今日以降で、今日から `years` 年（初期値 3）の内の年忌。確定・済みの法要がある（故人、回忌）の組は除く。`officiantName` は「住職 高橋 日照」の形
- 【決定】シードは撮影の前（2026-11-01）に受けたことにする（`createMemorialRequest` の `today`、`bookMemorialService` の `now`）
