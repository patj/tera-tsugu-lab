# 利用者ごとにできること

> 仕様書（[spec.md](spec.md)）の内容を、利用者の立場ごとに整理した資料。食い違ったときは spec.md を正とする。
> ※ メンタルケア（相談者、ケアのツール）は**保留中**。基本機能が完成してから組み込む（spec.md §7）。この資料では、組み込んだときの想定として残し、【保留中】と表示する。
> 記号: ◯ できる / △ 条件付きでできる（注を参照） / − できない / ？ 未決

## 利用者の立場

| 立場 | どんな人か | 入口 |
|---|---|---|
| **スタッフ** | 住職、副住職、執事長、奥様（寺庭婦人）、寺務員、アルバイトなど | 管理画面、MCP（Claude Desktop） |
| **檀家・施主** | 世帯の代表（`households.head_person_id` に設定されている人） | 檀家ポータル（招待コードで登録し、以降はメールのマジックリンクでログイン） |
| **檀家・家族** | 世帯に属する、施主以外の人 | 檀家ポータル |
| **檀家でない人** | 前撮りやお茶会の申込者、行事への一般参加者など | 公開ページ（ログインなし） |
| **相談者**【保留中】 | メンタルケアのツールを使う人。上のどの立場の人でもなりうる | ケアのポータル（匿名） |

※ 「相談者」は他の立場と重なりうる、横断的な立場。ケアのポータルは、ほかの立場のアカウントとは**ひもづけずに**匿名で使う（本人が希望した場合だけ、お寺と共有する）

## 立場ごとの一覧

> 各立場の人が「何ができるか」を、その人の目線で並べたもの。機能ごとの詳細な比較は、後半の「機能ごとの一覧」を参照。

### スタッフ（住職、副住職、執事長、奥様、寺務員、アルバイトなど）
入口: 管理画面、MCP（Claude Desktop）

- **台帳・過去帳**: すべての世帯、個人、故人を見る・登録する・直す・削除する（削除は管理画面だけ）。対応記録をつける
- **法要**
  - 年忌を迎える家を一覧する
  - 法要の申し込み（ポータルや電話で受けたもの）を確認する
  - 年忌を検証し（故人の取り違え、回忌と年の対応、命日より後の日でないか、併修）、担当者と本堂の空きから候補を出し、日時を確定させる
  - 電話で受けた申し込みを、代わりに登録する
- **スタッフのカレンダー**
  - 業務の予定（法要、行事、施設の立ち会い、外出、勤務）を見る・登録する・担当者を割り当てる
  - 自分の私的な予定を登録する・内容を見る。他の人の私的な予定は「予定あり」と時間だけが見える
- **施設予約**: カレンダーで空きを見る。予約を登録する。外部の人からの申請を承認する・断る
- **行事・アンケート**: フォームを作る・編集する（3 つの公開モード）。世帯ごとの個別リンクを発行する。集計を見る・CSV で出力する
- **檀家ポータルの管理**: 招待コードを発行する
- **メンタルケア**【保留中】
  - 相談者が共有に同意したツールの記録を見る（閲覧は監査ログに残る）
  - 危機アラートを受け取る（共有の同意がある人だけ）
  - お坊さんは、Claude Code で新しいケアのツールを作る
- **MCP**: 上の業務（ケアのデータと、他人の私的な予定の内容を除く）を、自然言語で照会・登録する（登録は 2 段階の確認を経る。削除はできない）
- できないこと: 同意のないケアの記録を見る、他人の私的な予定の内容を見る、MCP でケアのデータを扱う

### 檀家・施主（世帯の代表）
入口: 檀家ポータル（招待コードで登録し、以降はメールのマジックリンクでログイン）

- **自分の家の情報**: 家系図（故人を含む）を見る。家の法要の予定（確定した法要と、今後の年忌の目安）を見る
- **法要**: 家を代表して法要を申し込む（対象の故人、回忌、第 1〜第 3 希望、場所、人数、お斎の有無）。申し込みの状況（受付済み / 確定）を見る
- **行事**: 行事（花まつり、お会式など）に申し込む（台帳でわかる項目は聞かれない簡易版）。自分の申し込みを確認する
- **家族の管理**: 家族ごとに「家の情報を見られる」「代わりに法要を申し込める」の権限を与える・外す
- **相談者として**【保留中】: ケアのポータルを匿名で使う（ポータルのアカウントとはひもづかない）
- 未決: 自分の家の連絡先を直す、施設の利用を申請する
- できないこと: 他の家の情報を見る、法要の日時を自分で確定する

### 檀家・家族（施主以外の家族）
入口: 檀家ポータル（招待コードで登録し、以降はメールのマジックリンクでログイン）

- **行事**: 行事に申し込む（簡易版）。自分の申し込みを確認する
- **施主から許可された場合だけ**
  - 家系図と家の法要の予定を見る（`can_view_household`）
  - 施主の代わりに法要を申し込む（`can_apply_memorial`。誰が申し込んだかが記録される）
- **相談者として**【保留中】: ケアのポータルを匿名で使う
- 未決: 自分の連絡先を直す、施設の利用を申請する
- できないこと: 家族の権限を変える、許可なく家の情報を見る

### 檀家でない人（外部の利用者、行事への一般参加者）
入口: 公開ページ（ログインなし）

- **施設予約**: 施設の利用（前撮り、お茶会など）を申請する（申請した時点では仮押さえ。住職の承認で確定する）。申請番号で状況を確認する
- **行事**: 公開フォームから行事に申し込む（氏名や連絡先も入力する全項目版）
- **相談者として**【保留中】: ケアのポータルを匿名で使う
- 未決: 施設の空きの状況を見る
- できないこと: 台帳、法要、カレンダーに関わること全般

### 相談者（どの立場の人でもなりうる）【保留中】
入口: ケアのポータル（匿名。ニックネームだけで始められ、ID は端末に保存される）

- ケアのツール（こころの記録など）で記録する・自分の記録を振り返る
- ツールごとに「お寺と共有する / しない」を選ぶ。いつでも撤回できる（撤回するとすぐにお寺側から見えなくなる）
- 危機的な言葉を書くと、相談窓口が表示される
- 注意: 端末を変えたりデータを消したりすると、自分の記録には戻れない
- 相談者の記録は、MCP や AI からは一切参照されない

## 未決事項（？の箇所）

- 檀家が自分で連絡先を直せるか（スタッフの確認を挟むか）
- 檀家が施設の利用（例: お茶会）をポータルから申請できるか
- 檀家でない人に、施設の空きの状況を公開するか
- 業務の権限はスタッフ全員同じ（ハッカソン版）。本番では、アルバイトが台帳やケアのデータを見られないようにするなど、ロールを分けることを再検討する
