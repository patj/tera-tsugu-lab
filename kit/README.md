# はじめにお読みください：お寺のアプリ 開発キット

「お寺のアプリ」を作って、手元で試すためのキットです。
お寺のアプリは、日記、おみくじ、写経の記録など、お寺が「こんな機能がほしい」と思った機能です。利用する方は、スマートフォンから名前なしで（ニックネームだけで）使います。

このキットで作ったアプリを送っていただくと、こちらで確認してから、お寺のシステム（てらつぐ）に組み込みます。

## 1. 用意するもの

- パソコン（Mac または Windows）
- [Node.js](https://nodejs.org/ja)（22 以上）
- [Claude Code](https://docs.claude.com/ja/docs/claude-code/overview)（Claude と一緒にアプリを作ります）
- AI を使うアプリを作るときだけ: Anthropic の API キー（試すときに使います。お寺のシステムに組み込んだあとは、こちらのキーと費用で動きます）

## 2. はじめる

このフォルダで、ターミナル（Windows では PowerShell）を開いて、次を順に実行します。

```sh
npm install      # はじめの 1 回だけ
npm run dev      # 試す画面がブラウザで開きます
```

AI を使うアプリを試すときは、`.env.example` をコピーして `.env` という名前にし、`ANTHROPIC_API_KEY=` のあとに API キーを書いてから `npm run dev` をやり直します。
キーは、試す画面のサーバーだけが使い、ブラウザには渡しません。**`.env` は人に送らないでください**（アプリを送るときも入れません）。

## 3. アプリを作る

別のターミナルで、このフォルダで `claude` を起動し、作りたいものを伝えます。

頼み方の例:
- 「毎日ひとこと書ける日記のアプリを作りたい。書いた日記を、本人が希望したら住職に見せられるように」
- 「今日の運勢を引けるおみくじのアプリを作って。大吉から凶まで 7 種類で、引いた結果の履歴が残るように」
- 「日記を書くと、AI がその日の気持ちを服にしてくれるアプリ。画面全体を使って、絵本のような見た目にしたい。部品の画像は assets/ に置いてある」

Claude が、足りないこと（保存するもの、お寺と共有できるようにするか、AI を使うか、名前とアイコン）を聞いてから、`apps/<アプリの ID>/` にアプリを作ります。

### アプリでできること
- 利用する方ごとに、自由な形のデータを保存する（書く、読む、直す、消す、すべて消す）
- 利用する方が希望したときだけ、お寺と共有する（お寺の方は読むだけ）
- AI（Anthropic 社の Claude）に、日記の文字や写真を渡して、決まった形の答えをもらう（利用する方の同意を、システムが聞きます）
- 画像や音などの素材を使う（`assets/` に置く。SVG は使えません）
- 画面全体を使う、ホーム画面に追加して単独のアプリのように使う
- 音声入力、写真の選択、振動、音、画像の保存、スマートフォンの共有機能

## 4. 試す

`npm run dev` の画面（http://localhost:5173）で、上の選択欄から作ったアプリを選びます。

- **利用者の画面**: 書く、直す、消す、を試します。ページを読み直しても残っていることを確かめます。「スマホの幅」にチェックを入れると、スマートフォンの幅で見られます
- **AI を使う**アプリなら、初めて AI を呼ぶと同意の画面が出ます。同意しないときや、AI が失敗したときも、アプリが止まらないことを確かめます。AI を呼ぶたびに、ターミナルに使ったトークン数とおおよその費用が出ます
- **お寺と共有する**アプリなら、共有のボタン（または右上の「設定」、全画面のアプリでは右上の「⋯」）で共有し、**スタッフの画面**に切り替えて、お寺の方にどう見えるかを確かめます
- 「データを消す」で、試したデータと AI の同意を消せます

試す画面のデータは、このブラウザの中にだけ保存されます（お寺のシステムでは、暗号化してお寺のサーバーに保存されます）。

## 5. 送る

送る前に、次を実行して、どちらも問題がないことを確かめます。

```sh
npm run apps:check   # 決まりを守っているか（「規約違反はありません」と出れば OK）
npm run typecheck    # 書き間違いがないか（何も出なければ OK）
```

`apps/<アプリの ID>/` のフォルダを zip にして送ってください（`apps/_template` と `.env` は送らないでください）。

送っていただいたあとは、こちらでコードを読み、決まりを守っているか、外にデータを送っていないかを確かめてから、お寺のシステムに組み込みます。直してほしいところがあれば、ご連絡します。

## 6. 気をつけること・まだできないこと

- アプリを開くときに、その方のデータをすべて読み込みます。写真をデータに入れるときは、小さく縮めてください（データが多いと、開くのが遅くなります）
- iPhone では、ホーム画面に追加したアプリと Safari とで、利用する方が別になります（お寺のシステムに引き継ぎの仕組みを用意します。それまでは、ホーム画面に追加してから始めるよう案内してください）
- AI には、回数と費用の上限があります。上限に達すると AI が使えなくなるので、AI がなくても動くように作ってください
- まだできないこと（今後、検討します）: 1 件ずつお寺に送る（申し込み、回答など）、お寺の方が管理画面でアプリの内容を変える、檀家としてログインする、オフラインで使う、お知らせ（プッシュ通知）、AI での画像の生成、課金、外部のサービス（地図、天気など）を使う

## 7. 困ったときは

- 試す画面が開かない: `npm install` をもう一度実行し、`npm run dev` をやり直してください
- AI が「キーがありません」と言う: `.env` に `ANTHROPIC_API_KEY` を書いて、`npm run dev` をやり直してください
- Claude に「このキットの決まりに合っているか確かめて」と頼むと、`npm run apps:check` で確かめてくれます
- わからないことは、キットをお渡しした担当者にお問い合わせください
